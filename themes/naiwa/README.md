# 奶蛙 Naiwa 1.3

保留当前立体原画、透明动画和完整经典捧腹大笑，参照内置 Clawd 的反馈节奏改善自然度。

- 待机时向鼠标轻微趋近：最大水平 1.8px、垂直 0.6px、倾斜 0.45 度，约 110ms 缓动。它是身体反馈，不是独立眼球追踪。
- 指针停止后不持续运行 RAF；工作、权限、错误、拖拽、点击演出和睡眠不叠加此反馈。
- 新反馈支持减少动态效果偏好、窗口隐藏和低功耗暂停，不影响 Mini 模式的原有镜像。
- 待机循环 3.3 秒，思考 2.4 秒，工作 1 秒，打盹 4.2 秒，睡眠 4.8 秒。只调整 APNG 帧控制时长；压缩像素、帧数、透明度和原画均不变。
- 常规状态使用 80-110ms 的短过渡，权限、错误和完成反馈立即出现。单击反馈缩短到 1.2 秒，经典大笑绑定和原音效保留。

使用 Node.js 24 检查节奏：`node scripts/retime-naiwa-motion.js`；应用节奏：`node scripts/retime-naiwa-motion.js --apply`。重复执行不会累积变慢。

历史 `build-theme.py` / `improve-motion.py` 属于旧生成流程，可能覆盖现有原画版本，运行前应备份。当前实际绑定以 `theme.json` 为准。

窗口、任务栏、托盘及关于页继续使用奶蛙形象。内置 Clawd 和其他主题、兼容标识、配置路径及上游署名均保留。素材许可见 `THIRD-PARTY-NOTICES.md`。
